# MarketElite UI/UX 视觉设计规范（Style 4：白底丝绒 × 黑白相间组件）

> 核心美学原则：**告别千篇一律的“暗黑圆角荧光 SaaS 模板”**。采用高奢画廊暖丝绒白底色，以**纯粹的曜石黑丝绒块与画廊白卡片交替撞色**构建强烈建筑感，用克制排版与微交互聚光呈现专业金融终端质感。

---

## 1. 色彩系统（Color Tokens）

| 角色 | 色值 / 渐变 | 使用规范 |
| :--- | :--- | :--- |
| **主画布底色（Light Silk Velvet）** | `radial-gradient(circle at 50% 0%, #FFFFFF 0%, #F3F3F0 100%)` | 全局背景。柔和不刺眼的丝绒纸感，杜绝纯白 `#FFFFFF` 电子表眩光。 |
| **深色组件块（Obsidian Velvet Block）** | `#0B0B0D` + `1px solid #1C1C21` | 用于**顶部 Regime 总览、核心大盘主卡片、底部悬浮 Command 胶囊**等视觉重心，形成高反差锚点。 |
| **浅色组件块（Gallery White Block）** | `#FFFFFF` + `1px solid #E4E4E7` | 与黑色组件交替错落排列，承载风险审查详情、参数面板与日历表格。 |
| **主墨水文本** | 白底上 `#09090B` / `#52525B`；黑底上 `#FAFAFA` / `#A1A1AA` | 保证极高对比度阅读清晰度，减少无关辅助色干扰。 |
| **语义涨跌色（仅用于数据/状态点）** | 美股绿涨 `#10B981`（浅底 `#059669`） / 美股红跌 `#F43F5E`（浅底 `#E11D48`） / 警示琥珀 `#D97706` | **极其克制**：禁止大面积霓虹发光胶囊或色块铺底，只用于涨跌数字、微曲线和核心预警徽标。 |

---

## 2. 材质与微交互（Materiality & Motion）

1. **双向微光聚光灯（Dual Spotlight Hover）**：
   * 黑色丝绒组件：鼠标悬停跟随极微弱白色径向光晕（`rgba(255,255,255,0.08)`）+ 顶部 `1px` 内高光。
   * 白色画廊组件：鼠标悬停跟随极微弱炭影聚光（`rgba(0,0,0,0.035)`）+ 细腻柔和投影（`0 12px 28px -18px rgba(0,0,0,0.14)`）。
2. **排版与数字对齐**：
   * 标题与品牌：`Inter`（紧凑字距 `-0.02em`）配合局部衬线点缀。
   * 价格、收益率、延迟、仓位：`JetBrains Mono` + `font-variant-numeric: tabular-nums`，确保数字跳动时零像素抖动。
3. **流畅流程过渡（Framer Motion）**：
   * 统一使用 Expo 缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)` 与共享 `layoutId` 弹簧切换；
   * 唤醒 `Agent` 或 `HITL 人工下单确认` 时，底层画布平滑缩放微退，黑色或纯白强对比审查卡片顺滑浮现，过程节点逐级点亮。
